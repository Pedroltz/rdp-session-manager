# RDP Session Manager 0.5.1

This maintenance release fixes Arch Linux desktop environment detection, session startup configuration (`.xinitrc`), and introduces real-time EWMH window tracking for RemoteApp sessions.

## Key Changes & Bug Fixes

### 1. Arch Linux Package & Group Detection
- Fixed `DEInstaller.is_de_installed()` on Arch Linux to query `pacman -Qg` package groups in addition to single packages.
- Added system `PATH` binary verification (`shutil.which`) for DE startup commands (`startxfce4`, `gnome-session`, `startplasma-x11`).

### 2. Automatic `.xinitrc` Symlink Creation
- Updated all session helper scripts (`create-rdp-user.sh`, `change-session-type.sh`, `create-xsession.sh`, `update-rdp-user-profiles.sh`) to automatically generate `~/.xinitrc` symlinked to `~/.xsession`.
- Added automatic `.xinitrc` fallback creation in `UserManager._detect_session_info()`, preventing Arch Linux `/etc/xrdp/startwm.sh` from falling back to missing `xterm`/`xclock` scripts.

### 3. GNOME & KDE Plasma Session Compatibility
- Improved GNOME session launch logic to detect `gnome-flashback` vs standard `gnome-session` and export proper X11 desktop variables (`XDG_CURRENT_DESKTOP`, `XDG_SESSION_DESKTOP`, `DESKTOP_SESSION`).
- Added `KDE_SESSION_VERSION=6` export for KDE Plasma 6 sessions.

### 4. RemoteApp Lifecycle & Instant Disconnect
- Implemented real-time EWMH window tracking (`xprop -root _NET_CLIENT_LIST`) in RemoteApp launcher scripts.
- Solved premature session termination for Electron/forking applications (e.g., Visual Studio Code `code`, Chrome, Firefox, Flatpak, Snap).
- Ensured RDP sessions **instantly terminate and disconnect** when the application window is closed.
