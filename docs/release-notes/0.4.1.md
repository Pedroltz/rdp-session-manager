# RDP Session Manager 0.4.1

This release strengthens the installation and publishing pipeline with real
end-to-end checks on the Linux distributions supported by the project.

## Installation validation

- Release packages are installed and verified on Ubuntu 22.04, Ubuntu 24.04,
  Debian 12, Debian 13, and Arch Linux.
- The checks cover the application, command-line tools, desktop integration,
  xrdp, and the optional Wine dependencies.
- Supported derivative distributions remain covered by installer detection and
  package-resolution tests.

## Safer releases

- Release candidates are tested locally and again through the public GitHub
  `curl` installer.
- A candidate is promoted to the stable and latest release only after every
  public installation check passes.
- Failed candidates remain prereleases, preserving the previous stable release.
