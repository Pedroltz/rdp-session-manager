# RDP Session Manager 0.7.0

This major release introduces the **Operations & Health Diagnostics Center**, transactional user repair with automatic rollback, privileged execution auditing, capacity planning in the graphical Preferences dialog, and a comprehensive GTK 4 / Libadwaita user interface modernization.

## Key Changes & New Features

### 1. Operations Center & Health Diagnostics
- Added unified system, user, session, and Windows runtime health checks via `rdpsm health` and the graphical **System Health** dialog.
- Interactive filtering by status severity (`Healthy`, `Warning`, `Critical`, `Unknown`), component scope (`Host`, `User`, `Session`, `Windows runtime`), and text search.
- Structured human-readable evidence inspection with available remediation actions.

### 2. Transactional User Repair & Rollback
- Added guided and headless user account repair via `rdpsm repair user <name>`.
- Generates pre-execution repair plans, verifies preconditions, creates atomic backups in `/var/backups/rdp-session-manager/repair-<timestamp>`, and safely rolls back all changes if any step fails.

### 3. Privileged Audit Trail
- Introduced structured JSONL audit event streaming for all privileged actions under `/var/log/rdp-session-manager/audit.jsonl`.
- Added logrotate configuration for automatic log retention and compression.
- Export audit trails via CLI using `rdpsm audit export`.

### 4. Server & Capacity Management in UI
- Added a dedicated **Server & Capacity** page in the Preferences window.
- Configurable Linux session slots (`linux-light`), Windows session slots (`windows-standard`), max sessions, and host memory reserve percentage.
- Real-time visual memory budget gauge comparing allocated session RAM against safe host capacity.
- One-click **Auto-Detect / Recommend** button to set safe session limits based on physical hardware memory.
- Direct **Apply Server Profile** action to enforce resource isolation limits.

### 5. UI Modernization & Standardization (GNOME HIG)
- Standardized window aspect ratio (`800x620`) wrapped with responsive `AdwClamp` and breakpoints.
- Consistent dialog dimensions (`560x580` for user management, `640x520` for connection sources, `720x560` for system health).
- Cleaned up toast notifications, badge statuses, and tooltips across the application.
