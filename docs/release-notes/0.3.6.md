# RDP Session Manager 0.3.6

This release fixes clean Arch installations that do not already have an AUR
helper.

## Automatic yay bootstrap

- When neither `yay` nor `paru` is available, the installer downloads the
  official `yay-bin` PKGBUILD from the AUR.
- `makepkg` validates the upstream binary checksum and builds the local package
  before it is installed with `pacman`.
- The newly installed `yay` is then used to resolve and build `xrdp` and
  `xorgxrdp`.

## Visible authentication

- Long AUR operations are connected directly to the terminal.
- If the sudo timestamp expires during a build, the renewed password prompt is
  visible and can be answered instead of timing out behind the progress bar.
