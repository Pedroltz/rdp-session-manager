# RDP Session Manager 0.6.5

This release fixes user toggle session termination when disabling user accounts and fixes the graphical connection launcher for multi-profile RDP sessions.

## Fixed

- Force termination of active systemd/loginctl sessions (`loginctl terminate-user`) and user processes (`pkill -15` / `pkill -9`) when locking/disabling a user account.
- Present the fullscreen graphical connection source launcher (`rdp-session-launcher.py`) when logging into accounts with multiple configured connection profiles (e.g. Desktop Environment + WineGE Remote Application).
- Fixed JSON schema v2 profile parsing in `rdp-session-launcher.py`.

## Installer

The published installer bundle includes updated user lock helpers, connection launcher scripts, and versioned dispatchers for Debian, Ubuntu, Arch Linux, and compatible distributions.
