We're pleased to announce version **0.3.2**, a major release focused on a
reliable, transparent, and cross-distribution installation experience across
Debian-based and Arch-based systems. This release replaces the old installer
flow with a visual Python installer, robust package handling, and automated
release tooling.

---

### What's New

#### Visual Installation Experience

- **Rich Terminal Interface**: Added panels, component selection, spinners,
  progress bars, elapsed time, and native percentages when package managers
  provide real progress data
- **Transparent Installation Plan**: Shows the detected distribution, release,
  packages, optional components, AUR origin, multilib changes, and log path
  before authentication
- **Persistent Diagnostics**: Records commands, package-manager output, AUR
  output, downloads, warnings, and failures in the installation log
- **Local Development Mode**: Added `python -m installer --local` and
  `--dry-run` for testing an installation directly from a clone

#### Multi-Distribution Installation

- **Ubuntu/Debian Support**: Added detection and dependency handling for
  Ubuntu, Debian, Linux Mint, and Pop!_OS
- **Arch Support**: Added detection and dependency handling for Arch, Manjaro,
  EndeavourOS, and CachyOS
- **Safe Package Transactions**: Debian uses one `apt` update and install
  transaction; Arch uses `pacman -Syu --needed`
- **AUR xrdp Support**: Installs `xrdp` and `xorgxrdp` through `yay` or `paru`,
  with a transparent PKGBUILD fallback when no helper is available
- **AUR Verification**: Installs build prerequisites and imports PGP keys
  declared by official AUR PKGBUILDs

#### Optional Wine Support

- **Interactive Wine Selection**: WineGE dependencies are installed only after
  explicit user selection
- **Arch multilib Setup**: Automatically enables `[multilib]` when required and
  preserves `/etc/pacman.conf.rdpsm.bak`
- **Complete Runtime Dependencies**: Adds 64-bit and 32-bit Wine libraries,
  Vulkan loaders, Winetricks, 7zip, and supporting tools

### Key Improvements

| Area | Description |
|------|-------------|
| **Reliability** | Three download attempts, bounded timeouts, cleanup of temporary files, and idempotent reruns |
| **Security** | SHA-256 verification before package installation and PGP validation for AUR PKGBUILDs |
| **Transparency** | Complete pre-install plan, visible confirmations, persistent logs, and no hidden package-manager output |
| **Packaging** | Automated DEB, Arch package, bootstrap, Python installer, zipapp, and `SHA256SUMS` generation |
| **Project Organization** | Installation and release tooling is organized under `installer/` |

---

### Bug Fixes

- **Hidden Confirmations**: Fixed prompts being hidden behind live progress
  displays and making the installer appear frozen at 0%
- **Arch Package Handling**: Removed unsafe isolated `pacman -Sy` usage and
  fixed current Arch package names such as `7zip`
- **AUR Fallback Builds**: Fixed missing build tools and undeclared PGP key
  imports when `yay` or `paru` is unavailable
- **Progress Rendering**: Progress displays now pause correctly during
  confirmations and use native percentages when available
- **CI Distribution Fixture**: Fixed the Arch dependency test from reading the
  Ubuntu runner's `/etc/os-release`
- **Release Packaging**: Added `libarchive-tools` so `bsdtar` is available when
  building Arch packages on Ubuntu runners

---

### Security Enhancements

- **Artifact Verification**: SHA-256 checksums are validated before package
  installation
- **AUR Integrity**: PKGBUILD PGP fingerprints are imported and verified before
  compilation
- **Privilege Transparency**: Authentication is requested only after the
  complete installation plan is displayed
- **Configuration Backup**: The original pacman configuration is preserved
  before enabling multilib
