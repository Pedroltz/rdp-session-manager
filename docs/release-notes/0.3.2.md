**Release Date:** July 28, 2026

We're pleased to announce RDP Session Manager 0.3.2, a major installation and
distribution support update focused on reliable setup, transparent operations,
and a smoother terminal experience across Ubuntu/Debian and Arch Linux.

## What's New

### Visual, Transparent Installer

- **Rich terminal interface**: Clear panels, component selection, progress bars,
  spinners, elapsed time, and native percentages when package managers provide
  real progress data.
- **Safe release bootstrap**: The public `install.sh` downloads the versioned
  installer, validates SHA-256 checksums, and then starts the Python installer.
- **Detailed diagnostics**: Commands, package-manager output, AUR output, and
  download failures are preserved in
  `~/.local/state/rdp-session-manager/install.log`.
- **Local development mode**: Test the installer from a clone with
  `python -m installer --local` or preview it with `--dry-run`.

### Ubuntu/Debian and Arch Support

- Automatic detection of Ubuntu, Debian, Linux Mint, Pop!_OS, Arch, Manjaro,
  EndeavourOS, and CachyOS.
- One synchronized `apt` transaction on Debian-based systems, including the
  local application package and its dependencies.
- Safe `pacman -Syu --needed` handling on Arch instead of an isolated database
  refresh.
- `xrdp` and `xorgxrdp` installation through `yay`/`paru`, with a transparent
  official AUR PKGBUILD fallback when no helper is available.
- Automatic installation of AUR build prerequisites and PGP key validation.

### Optional Wine Support

- Interactive WineGE dependency selection.
- Automatic Arch `multilib` activation when required, with a backup at
  `/etc/pacman.conf.rdpsm.bak`.
- 64-bit and 32-bit Wine libraries, Vulkan loaders, Winetricks, 7zip, and
  supporting tools.

## Key Improvements

| Area | Description |
|------|-------------|
| **Reliability** | Three download attempts, bounded timeouts, cleanup of temporary files, and idempotent reruns |
| **Security** | SHA-256 verification before package installation and PGP validation for AUR PKGBUILDs |
| **Transparency** | Complete pre-install plan, explicit AUR/multilib origins, visible confirmations, and persistent logs |
| **Packaging** | Release workflows now generate DEB, Arch package, bootstrap, Python installer, zipapp, and `SHA256SUMS` |
| **Project layout** | Installation and release tooling is organized under `installer/` |

## Bug Fixes

- Fixed interactive confirmations being hidden behind live progress displays.
- Fixed Arch Wine package names and added the required 32-bit Vulkan loader.
- Fixed Arch fallback builds requiring undeclared PGP keys and build tools.
- Fixed the CI Arch dependency test from reading the Ubuntu runner's
  `/etc/os-release`.
- Added `bsdtar`/libarchive tooling to the release builder so Arch packages are
  generated reliably on Ubuntu runners.

## Documentation and Validation

- Updated installation, local testing, AUR, Wine, troubleshooting, and
  uninstallation documentation.
- Added Ubuntu and Arch installer smoke tests to GitHub Actions for pushes to
  `main`, `master`, and `develop`, plus pull requests.
- The release was validated with the full unit-test suite and real Ubuntu and
  Arch smoke environments.

## Installation

Stable channel:

```bash
curl -fsSL https://github.com/Pedroltz/rdp-session-manager/releases/latest/download/install.sh | bash
```

Beta channel (`v0.3.2-Beta`):

```bash
curl -fL https://github.com/Pedroltz/rdp-session-manager/releases/download/v0.3.2-Beta/install.sh -o install.sh
bash install.sh
```
