# RDP Session Manager 0.3.4

This patch release restores interactive prompts for the documented
`curl | bash` installation command.

## Fixed

- The bootstrap reads installer answers from the controlling terminal after
  consuming the script from stdin.
- Non-interactive environments receive a clear error unless `--yes` is used.

## Validation

- An end-to-end pseudoterminal test reproduces the documented pipe command and
  confirms that the installer receives interactive input.
- Existing checksum, release-bundle, Ubuntu, and Arch tests remain enabled.
