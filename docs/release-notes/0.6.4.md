# RDP Session Manager 0.6.4

This release stabilizes the complete Windows RemoteApp flow, from account
creation through interactive application installation and later RDP logins.

## Fixed

- Request administrative authentication only once while creating or repairing
  a managed RDP user.
- Roll back partially created accounts even when UMU leaves user processes
  running.
- Pre-download and validate the shared UMU runtime before the first RDP login.
- Fall back to the installed system Wine when the Steam runtime repository is
  temporarily unavailable.
- Detect the application executable created by an interactive installer,
  update the connection profile, and open it automatically.
- Prevent stale compatibility wrappers from reopening the original installer.
- Show Notepad++ correctly in the Available Executables list while continuing
  to hide Wine system tools, updaters, and uninstallers.
- Use the current libadwaita dialog API for nested executable selection.

## Installer

The published installer bundle includes the new prewarm, repair, session
dispatcher, and dynamic Windows application launcher helpers for Debian,
Ubuntu, Arch Linux, and compatible distributions.
