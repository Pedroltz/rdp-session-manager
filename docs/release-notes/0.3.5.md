# RDP Session Manager 0.3.5

This release simplifies GitHub distribution while preserving the existing
installation command and compatibility with older tags.

## Simplified release

- GitHub Releases now publish only `install.sh` and
  `rdp-session-manager-installer.zip`.
- The ZIP contains the Rich installer, Debian package, Arch package and their
  internal checksum manifest.
- The bootstrap validates the ZIP against the SHA-256 digest reported by the
  GitHub Releases API before extracting it.

## Compatibility and cleanup

- `--release` can still install older releases that use separate
  `installer.pyz` and `SHA256SUMS` assets.
- Temporary bootstrap files are removed after the installer exits.
