# RDP Session Manager 0.6.3

This hotfix corrects UMU provisioning on systems that use the official
distribution-independent zipapp, including Ubuntu 26.04.

## Fixed

- Accept the official relative `umu_run.py -> umu-run` symbolic link.
- Extract the verified UMU archive successfully without weakening archive
  validation.
- Continue rejecting absolute symbolic links, links that escape the extraction
  directory, parent-path traversal, and unsupported member types.

The exact official UMU 1.4.0 zipapp used by the installer was checksum-verified
and extracted successfully during validation.
