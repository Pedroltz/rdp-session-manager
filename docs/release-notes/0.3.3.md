# RDP Session Manager 0.3.3

This patch release restores the public autoinstaller and strengthens release
validation.

## Fixed

- The bootstrap accepts both standard `sha256sum` filename markers:
  `installer.pyz` and `*installer.pyz`.
- The public installation command resolves the latest stable GitHub release
  while `--release vX.Y.Z` remains available for pinned versions and explicit
  prereleases.

## Release safeguards

- Release builds verify all six required assets before publishing.
- Checksums are validated inside the release job.
- Bootstrap tests cover text and binary checksum formats, missing entries, and
  invalid hashes.
