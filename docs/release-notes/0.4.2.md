# RDP Session Manager 0.4.2

This release extends the installation pipeline by proving that an installed
system can authenticate and render a real remote desktop session.

## Real RDP desktop validation

- Creates a temporary XFCE user through the installed `rdpsm` command.
- Connects to the local xrdp server with FreeRDP inside an Xvfb display.
- Requires the XFCE session process and an autostart marker created from inside
  the remote desktop.
- Captures the client display and rejects blank screenshots.
- Always terminates the session and removes the temporary user and home.

## Release diagnostics

- The Ubuntu 24.04 quality check runs the desktop test on every pull request.
- The same test gates publication of the release candidate.
- FreeRDP output, the rendered screenshot, xrdp journals, and Xorg session logs
  are uploaded even when the test fails.
