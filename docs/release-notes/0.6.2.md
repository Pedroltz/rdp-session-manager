# RDP Session Manager 0.6.2

This corrective release makes Windows RemoteApp account creation reliable when
UMU was not selected or available during the original installation.

## Fixes

- Provision `umu-run` before creating a Windows RemoteApp system account.
- Roll back partially created accounts and home directories when setup fails.
- Copy only the selected `.exe` into the RDP user's `WindowsApps` directory.
- Recognize the current profile dispatcher without repeated unknown-session
  warnings.
- Display the underlying helper error in the UI.

## Installer

- Windows RemoteApp dependencies are enabled by default for interactive and
  unattended installs.
- Minimal installations can explicitly opt out with `--without-wine`.
- On-demand UMU provisioning supports Arch Linux, supported Ubuntu and Debian
  versions, newer compatible releases, and derivatives through the verified
  distribution-independent zipapp fallback.

The DEB package, Arch package, bootstrap script, and installer bundle were
validated before publication.
