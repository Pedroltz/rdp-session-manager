# RDP Session Manager 0.5.2

This maintenance release fixes the Connection Sources UI rendering glitch when adding new sources, adds a "Make Default" action button in the profile management list, and enables fullscreen RDP connection launching.

## Key Changes & Bug Fixes

### 1. Connection Sources UI Glitch Fix
- Fixed an issue in `ConnectionSourcesDialog` where adding a new connection source caused existing profile rows to duplicate ("clone") in the UI list.
- Implemented explicit `_added_rows` tracking to cleanly remove previous `Adw.ActionRow` widgets before re-populating profile rows.

### 2. Profile Management Actions & UI Sync
- Added a "Make Default" (`emblem-favorite-symbolic`) action button directly in the profile management list for non-default profiles.
- Added automatic real-time parent window UI synchronization (`self.parent.load_users()`) whenever profiles are added, deleted, or updated.

### 3. Fullscreen RDP Connection Launching
- Configured the FreeRDP client launcher in the GTK4 GUI to launch RDP sessions directly in full screen mode (`/f`) with dynamic resolution negotiation.
