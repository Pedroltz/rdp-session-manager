# RDP Session Manager 0.4.0

This minor release standardizes the user experience in English while retaining
the installation and release reliability improvements from the 0.3.x series.

## English throughout

- The graphical application, CLI, helper scripts, and installer now present
  their user-facing messages in English.
- Desktop and AppStream metadata are also aligned with the English interface.

## Installation reliability

- The verified release bundle, SHA-256 checks, legacy release compatibility,
  and interactive `curl | bash` terminal support remain available.
