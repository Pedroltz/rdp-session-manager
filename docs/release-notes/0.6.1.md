# RDP Session Manager 0.6.1

This release adds an automated lifecycle for Windows applications exposed
through RDP while preserving existing WineGE profiles.

## Highlights

- Isolated compatibility prefix, manifest, state, logs and runtime per Windows
  application.
- Automatic MSI, silent EXE and portable application installation.
- Assisted RDP installation when an EXE has no known unattended mode.
- Executable discovery, selection, local Xvfb smoke testing and final RDP
  readiness tracking.
- Maintained UMU/Proton runner with WineGE/system Wine compatibility fallback.
- Pinned Notepad++ 8.9.6.1 recipe with its official SHA-256 checksum.
- On-demand migration of shared legacy WineGE prefixes.
- New `rdpsm windows-app` commands and basic GTK profile integration.

The Notepad++ MSI was installed silently and opened successfully under Wine
during local release validation. GitHub Actions checks were removed from
`develop` and `master`; tagged releases only build and publish installer assets.
