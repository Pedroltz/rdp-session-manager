# Gerenciador de sessões RDP
> Criar uma aplicação para criar, excluir e gerenciar usuarios com sessões RDP

A ideia geral seria criar uma aplicação ultilizando GTK4 junto ao pacote de aparencia do Gnome, para ficar adaptado para o ecosistema Gnome. Este aplicativo teria as seguintes 
finalidades:

    * Interface grafica GNOME para criar novas sessões de usaurio e conexões RDP.
    * Capacidade de poder escolher qual ambiente grafico cada novo usuario deve instalar.
    * Os usuarios deve ser instalados em uma outra pasta separada dos usuarios padões do sistema.
    * Tela de gerenciamento, onde cada usuario criado pode ser visualizado o endereço de ip para conexão, abiente grafico instalado e se esta ativo ou não.
    * no momento de criação do usuario, deve ser tudo automatizado, o usuario pode escolher o nome, senha e etc.
